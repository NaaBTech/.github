# The organization profile: a proposal

**Status: a proposal for the organization owners. The published profile is not changed by this document.**

## The gap

The published profile invites the reader to explore the public repositories. The profile previously carried a section heading that promised projects without listing any.

Neither problem is a matter of taste. The first makes the profile read as though something is missing, and the second is a heading that does not deliver on its name.

## The proposal

The change keeps the brand, the tagline, the three areas of activity, and every contact channel exactly as they are. It replaces the section about public repositories with a paragraph that introduces the products without promising source code that is not published, and it renames the section so that it describes what it actually contains.

```markdown
## What We Build

NaaB Tech builds software and technology across cybersecurity, software, and IT solutions.

Our public repositories are the best place to see how we work: the contribution guidelines, the security policy, and the tooling that keeps them honest are all open, and contributions to them are welcome. Each project sets its own scope and contribution process, so the repository itself is the best place to start.
```

## What this does not change

- The brand name, the tagline, and the three areas of activity.
- Every contact channel, and the links to the contribution guidelines, the code of conduct, and the security policy.
- The visibility of any repository. No confidential detail about a product is described.
- The published profile. This document is a proposal; changing the profile is the owners' decision.
